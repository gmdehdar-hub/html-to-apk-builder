## How to Build the APK

### Method 1: Android Studio (Recommended)
1. Open Android Studio (Ladybug / Hedgehog or newer).
2. Choose **File > Open...** and select this unzipped root directory.
3. Wait for Gradle Sync to complete.
4. Select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. Your APK will be located at:
   `app/build/outputs/apk/debug/app-debug.apk`

### Method 2: Command Line (CLI)
Make sure you have JDK 17 installed and Android SDK configured.
```bash
# Build Debug APK
./gradlew assembleDebug

# Build Release APK
./gradlew assembleRelease
```

### Method 3: 1-Click Cloud Build via GitHub Actions
This project includes `.github/workflows/build-apk.yml`.
1. Create a GitHub repository and push this project.
2. Go to the **Actions** tab in GitHub.
3. The APK will automatically build and become downloadable in the **Artifacts** section!
